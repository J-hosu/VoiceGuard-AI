# 추후 구현 사항

2026-11-18 기준으로 아직 구현하지 않았거나 확인하지 못한 항목입니다. 끝낸 항목은 이 목록에서 지웁니다. 기능별 한계와 평가 조건은 각 문서의 한계 절에 있습니다.

## 기능

- **보호자 등록과 수신 확인**: 보호자 알림은 위험 통화 이벤트를 n8n으로 보내 전송을 요청하는 데까지만 합니다. 앱에 보호자를 등록하는 화면이 없고, 보호자가 알림을 받았는지 확인하지 않습니다. 시연 서버의 n8n은 이 이벤트를 Slack 채널에 알립니다.
- **실제 통화 연동**: 웹 앱은 휴대폰 통화 음성을 직접 가져오지 않고, 기기 마이크로 들어오는 소리를 전사합니다. 실시간 분석은 웹 앱에만 연결돼 있습니다.
- **정기 수집 연결 여부**: 신종 수법은 수동 수집을 지원합니다. 정기 수집 워크플로는 템플릿만 제공합니다(`n8n/voiceguard_knowledge_collect.json`). n8n에 연결하지 않았고, 지금은 연결할 계획이 없습니다. 연결하려면 템플릿을 n8n에 가져와 `base_url`과 관리 코드를 넣습니다. 서버에 `ADMIN_CODE`가 없으면 접속 코드를 넣습니다.
- **동시 통화 수 확장**: Whisper가 음성 조각을 한 번에 하나씩 전사하므로, 동시에 처리할 수 있는 실시간 통화는 서버에 따라 약 2~4통으로 추정합니다. 2026-11-17에 금감원 녹취의 조각당 전사 시간으로 계산한 값이며 부하 시험은 하지 않았습니다. 통화가 그보다 많으면 오류는 나지 않지만 전사와 경고가 늦어집니다. Whisper 모델을 여러 개 띄워 조각을 나눠 전사하는 방식은 구현하지 않았습니다. 계산 근거는 [RunPod 이전 안내](DEPLOY_RUNPOD.md)에 있습니다.
- **기본 설정의 화자 구분**: 기본 설정(모두 로컬)에서는 화자를 구분하지 않습니다. 실시간 조각은 모두 한 화자로 두고, 통화 후 역할은 상태 추적기가 내용으로 정합니다. 리턴제로를 켠 서버(시연 서버)에서만 녹음 파일 분석, 통화 후 재전사, 통화 중 전사 보정이 화자를 나눕니다. 로컬 화자 분리 모듈은 시험만 했고 앱 흐름에 연결하지 않았습니다.
- **이미지 게시글 판독**: 본문이 이미지뿐인 게시글(경찰청 카드뉴스 등)은 수법 카드로 만들지 않고 주소만 기록합니다(`status=skipped`).

## 평가

- **실제 통화 평가 확대**: 전체 시스템 평가는 대본 글을 실시간 경로에 넣은 것이라 음성과 실시간 조각 전사를 거치지 않았습니다. 음성을 실시간 경로로 흘려 경고 시점을 기록한 시험은 분류기 v2 때의 금감원 녹취 2건과 합성 음성 정상 상담 1건뿐이고, 실제 이름·번호가 나오는 정상 통화로는 오경보율을 재지 않았습니다. 평가 조건과 한계는 [보이스피싱 탐지 성능](tech/detection.md)에 있습니다.
- **자동 테스트**: 저장소에 자동 테스트가 없고 `eval_*` 평가 스크립트만 있습니다.

## 운영

- **수법 카드 검토**: 2026-11-15 기준 시연 서버에 검토 대기 수법 카드 8장이 있습니다. 승인하면 상태 추적기 프롬프트가 바뀌고 회귀 평가가 돕니다(Claude API 비용 발생).
- **개인정보 안내 보완**: 2026-11-18에 수사관 자연어 질의를 시연 서버의 n8n에 연결했습니다. 수사관이 물으면 통화 요약·단서·위험 발화·전사 앞부분이 Claude API로 전송되고 질문과 답이 n8n을 거치지만, 참가자 개인정보 안내(`frontend/src/core/config/privacy.ts`)에는 이 내용이 없습니다.
- **서버 로그 정리**: 서버 로그(`backend/app/api/response_logger.py`)에 전사문 일부가 남습니다. 공개 시연 뒤에는 로그를 지우거나 줄입니다.

## 코드 정리

- **확인 응답 중복 저장**: 결과 화면에서 확인 응답을 다시 보내면 중복 저장됩니다. 화면이 보낸 상태를 기억하지 않습니다.
- **SQLite 외래 키**: `PRAGMA foreign_keys`를 켜지 않아 `ON DELETE CASCADE`가 동작하지 않습니다.
- **쓰지 않는 모듈**: `realtime_detector.py`, `llm_judge.py`, `predict.py`, `train_baseline.py`, 루트의 `realtime_stt.py`, `convert_nia_dataset.py`는 서비스에서 쓰지 않습니다.
- **ERD**: `docs/ERD.md`는 v1 테이블 6개만 그립니다.
