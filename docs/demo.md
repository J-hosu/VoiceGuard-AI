- **통화 영상의 기록 조건** — 2026-11-20에 현재 구성(통화 분류기 v5)으로 기록했습니다. 금융감독원이 공개한 수사기관 사칭 통화 녹음의 앞 90초(음성 변조)를 브라우저의 마이크 입력으로 넣었고, 앱은 실제 통화처럼 소리를 조각으로 서버에 보냈습니다. 서버는 Whisper large-v3로 받아 적은 뒤 분류기, 상태 추적기, 대응 에이전트를 실제 앱과 같은 코드로 실행했습니다.
- **통화 영상의 음원** — 화면을 기록할 때 넣은 것과 같은 녹음을, 마이크가 열린 시각에 맞춰 영상에 넣었습니다. 말이 들리고 몇 초 뒤에 그 말의 전사가 화면에 나타납니다. 변조된 음성이라 전사에 틀린 글자가 섞여 있습니다.
- **재생 속도** — 실제와 같습니다. 통화가 끝난 뒤 결과를 기다리는 약 15초만 빠르게 재생했고, 화면에 그렇게 표시했습니다.
- **화면의 정보** — 통화 영상의 전사문과 단서(날짜, 금액, 이름 등)는 공개된 녹음에서 받아 적은 것입니다. ‘이 사건번호는 다른 의심 통화에도 나왔어요’ 카드는 같은 녹음으로 한 이전 시험 통화가 기록에 있어 나온 것입니다. 나머지 두 편의 이름, 전화번호, 계좌번호, 사건번호는 가상 정보이며, 대시보드의 통화는 모두 시험 통화입니다.
- **나머지 두 편** — 2026-11-18에 기록했습니다.
- **README의 움직이는 그림** — 아래 통화 영상 두 편과 같은 녹화에서 일부 구간을 이어 붙여 만든 것입니다(소리 없음).
- **녹음의 출처** — 통화 녹음은 금융감독원이 보이스피싱 예방을 위해 공개한 실제 사기 통화 녹취입니다. 권리자의 요청이 있으면 내리겠습니다.

## 실시간 통화 분석

왼쪽은 사용자 화면이고 오른쪽은 서버의 판단 과정을 보여 주는 'AI 분석 과정' 패널입니다. 카드사 개인정보 유출을 묻는 첫 말에서는 위험도가 0\~7%로 낮게 시작합니다. 불법 도박·금융사기 일당을 검거했다는 말이 나오자 수사기관 사칭형으로 판단해 72%(주의)가 되고, 압수한 통장 이야기가 이어지면서 86%를 넘어 전체 화면 경고가 뜹니다. 이후 90\~94%로 오르고, 통화가 끝나면 최종 97%로 정리합니다.

## 휴대폰 화면

같은 통화 녹음을 휴대폰 화면으로 따로 실행해 기록했습니다. 통화 중의 경고와 대응 카드에 이어, 통화가 끝난 뒤의 분석 결과(97%)와 '돈을 보냈어요'라고 답했을 때의 지급정지 안내까지 이어집니다. 위 영상과 다른 실행이어서 중간 위험도가 조금 다릅니다(위 영상은 72%를 거쳐 86%, 이 영상은 79%를 거쳐 86%).

## 문자 검사와 문서 점검
