VoiceGuard AI의 주요 화면을 처음부터 끝까지 보여 주는 영상 네 편입니다. 모두 자막으로 설명하며, 통화 영상 두 편에는 통화 대본을 읽은 음성이 들어 있습니다. 나머지 두 편은 소리가 없습니다.

- **기록 조건** — 2026-11-18에 현재 구성(통화 분류기 v5)으로 기록했습니다. 통화 영상은 검찰 사칭 대본을 한 문장씩 글로 보낸 대본 시연이며, 마이크 입력과 음성 전사는 거치지 않았습니다. 이후의 분류기, 상태 추적기, 대응 에이전트는 실제 앱과 같은 코드로 실행했습니다.
- **통화 영상의 음성** — 대본의 일곱 문장을 Windows 기본 음성 합성으로 읽게 한 뒤 영상에 입혔습니다(2026-11-20). 앱이 이 음성을 듣고 전사한 것은 아니며, 앱에는 같은 문장을 글로 보냈습니다. 각 문장이 끝나는 시점을 해당 문장을 보낸 시점에 맞췄으므로, 문장을 듣고 나면 곧 화면에 전사 결과가 나타납니다. 두 사람을 구별하려고 전화를 건 쪽의 목소리를 낮췄습니다.
- **재생 속도** — 실제와 같습니다. 통화 영상은 발화 사이의 대기 시간도 자르지 않았습니다.
- **화면의 정보** — 이름, 전화번호, 계좌번호, 사건번호는 가상 정보이며, 대시보드의 통화는 모두 시험 통화입니다.
- **README의 움직이는 그림** — 아래 통화 영상 두 편에서 일부를 잘라 만든 것입니다.

## 실시간 통화 분석

왼쪽은 사용자 화면이고 오른쪽은 서버의 판단 과정을 보여 주는 'AI 분석 과정' 패널입니다. 첫 문장 직후 통화 분류기가 99.97%를 주어 전체 화면 경고가 뜨고, 경고를 닫으면 상태 추적기가 대화 맥락으로 다시 계산한 65%가 표시됩니다. 이후 사칭(72%), 위기 조성(86\~90%), 고립(97\~98%), 금전 요구(99%)로 단계가 넘어가면서 대응 카드가 쌓입니다.

## 휴대폰 화면

같은 대본을 휴대폰 화면으로 따로 실행해 기록했습니다. 통화 중의 경고와 대응 카드에 이어, 통화가 끝난 뒤의 분석 결과와 '돈을 보냈어요'라고 답했을 때의 지급정지 안내까지 이어집니다. 위 영상과 다른 실행이어서 경고를 닫은 뒤의 위험도가 조금 다릅니다(위 영상은 65%를 거쳐 72%, 이 영상은 바로 72%).

## 문자 검사와 문서 점검
